# Link

1. Confirm what the target is and when it should be used, in one question if unclear. Check that it
   exists. A web address that cannot be opened is marked "not checked".
2. Pick the right map: the `CLAUDE.md` of the folder it belongs to (a domain under
   `internal/Domains/`, the ASB work folder, `Brain/`). The root `CLAUDE.md` gets a line only for a
   whole new area.
3. Add one line: when to use it, then the exact path or link. Do not copy its contents into the map.
4. A new folder with no `CLAUDE.md` gets one from `Brain/Templates/ClaudeMD-template.md`.
5. Read the route back from the root map down to the target to prove it resolves. Tell her where the
   line went in one sentence.

Never move or delete the target, and never put a password or key in a map.
