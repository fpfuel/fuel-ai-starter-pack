# Housekeeping

- Never delete. Move old or replaced things to `internal/Trash/<YYYY-MM-DD>/`.
- Record a decision the moment she makes it, in `Brain/Decisions/log.md`, one line:
  `[YYYY-MM-DD] DECISION: ... | WHY: ... | CONTEXT: ...`
- Memory is one fact per file in `Brain/memory/`, made from `Brain/Templates/memory-template.md`,
  with one line in `Brain/memory/MEMORY.md` pointing to it. Check for an existing file first and
  update it rather than adding a second.
- Every new folder she starts gets a `CLAUDE.md` from `Brain/Templates/ClaudeMD-template.md` and
  a line in the `CLAUDE.md` of the folder above it, so it can be found next time.
- When she asks for the same kind of job a third time, offer to make it a skill from
  `Brain/Templates/skill-template.md`.
- Keep every `CLAUDE.md` short. A map points; it does not store.
